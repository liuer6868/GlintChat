## 1. 逐项核实结果

### 1.1 智谱 AI BigModel ✅ 推荐

- **免费形式**：永久免费模型（按量计费但单价为 0，账单显示免费）
- **OpenAI 兼容 base_url**：`https://open.bigmodel.cn/api/paas/v4/`
  - 完整 endpoint：`POST https://open.bigmodel.cn/api/paas/v4/chat/completions`
- **当前免费模型（官方定价页逐条抄录）**：

| model id | 上下文 | 类型 |
|---|---|---|
| `glm-4.7-flash` | 200K（最大输出 128K） | 文本，**首选** |
| `glm-4-flash-250414` | 128K | 文本 |
| `glm-z1-flash` | 128K | 文本（推理） |
| `glm-4.6v-flash` | — | 视觉 |
| `glm-4v-flash` | 4K | 视觉 |
| `glm-4.1v-thinking-flash` | 64K | 视觉推理 |
| `cogview-3-flash` | — | 文生图 |
| `cogvideox-flash` | — | 文生视频 |

- **`glm-4.7-flash` 能力**：支持 `stream: true`、`thinking: {type: "enabled"}`（深度思考，返回 `reasoning_content`）、Function Calling、结构化输出、上下文缓存、MCP。官方 cURL 示例已给出 `stream` 用法。
- **账号要求**：手机号注册，中国平台，需实名认证
- **限流**：按**并发数**限制（不是 RPM），不同模型独立、按账户权益等级划分；高峰期动态限流。超额：错误码 `1302`（用户速率限制）、`1305`（平台过载）。免费模型并发很低（第三方资料称约 1 并发，**未在官方页面确认**）
- **数据用于训练**：智谱隐私政策未明确承诺不用于训练，商用前请自行阅读协议
- **文档**：[OpenAI API 兼容](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)、[API 定价](https://docs.bigmodel.cn/cn/guide/start/pricing)、[速率限制](https://docs.bigmodel.cn/cn/api/rate-limit)

### 1.2 硅基流动 SiliconFlow ✅ 推荐

- **免费形式**：**永久免费模型**（账单中费用为 0）+ 注册赠送额度
- **OpenAI 兼容 base_url**：`https://api.siliconflow.cn/v1`（海外：`https://api.siliconflow.com/v1`）
- **免费 model id**（第三方整理，**官方模型广场为动态列表，需自行核对**）：
  - `Qwen/Qwen3-8B`（通用对话，262K 上下文）
  - `deepseek-ai/DeepSeek-R1-Distill-Qwen-7B`（推理蒸馏）
  - `deepseek-ai/DeepSeek-OCR`（文档 OCR）
  - `deepseek-ai/DeepSeek-R1-0528-Qwen3-8B`
  - `THUDM/glm-4-9b-chat`
  - `THUDM/GLM-4.1V-9B-Thinking`（视觉）
- **注册赠送**：多来源称 `.cn` 平台历史赠送 **¥14 / 约 2000 万 tokens**，`.com` 平台约 **$1**。⚠️ **官方文档（财务相关页）未提及该赠送**，仅实名为充值/开票前提 → 属**未确认**信息
- **账号要求**：需**实名认证**（个人支付宝扫脸 / 企业法人认证）。官方原文：「**实名认证后使用全部的免费模型**」；未实名的模型会返回 **403**
- **限流**（官方）：语言模型 `RPM=1000-10000`、`TPM=50000-5000000`；**免费模型为固定值**；限流按**账户**而非 API Key 计算，每个模型独立。超额返回 429
- **数据用于训练**：官方隐私政策称 API 请求数据在处理后不存储
- **文档**：[快速上手](https://docs.siliconflow.cn/cn/userguide/quickstart)、[Rate Limits](https://docs.siliconflow.cn/cn/userguide/faqs/rate-limit-and-upgradation)、[实名认证](https://docs.siliconflow.cn/cn/userguide/faqs/authentication)

### 1.3 DeepSeek 开放平台 ❌ 无免费额度

- **免费形式**：**没有免费额度**，纯按量付费（官方定价页只列付费单价）
- **OpenAI 兼容 base_url**：`https://api.deepseek.com`（也常写作 `https://api.deepseek.com/v1`）
  - Anthropic 格式：`https://api.deepseek.com/anthropic`
- **当前模型**：`deepseek-flash`（DeepSeek-V4.1-Flash）、`deepseek-v4-pro`（DeepSeek-V4-Pro-0813）
  - 旧的 `deepseek-v4-flash` / `deepseek-v4-flash-vision-exp` 已退役但仍接受，请求会被路由到 V4.1-Flash 并按 Flash 计费
- **价格**（每百万 tokens，官方）：
  - `deepseek-flash`：缓存命中 $0.003（低峰）/ $0.006（高峰）；缓存未命中输入 $0.15 / $0.30；输出 $0.6 / $1.2
  - `deepseek-v4-pro`：缓存命中 $0.022 / $0.044；输入 $0.66 / $1.32；输出 $1.98 / $3.96
  - 低峰价为高峰价的一半；高峰时段 = UTC 周一至周五 01:00-04:00 与 06:00-10:00（不含中国法定节假日）
- **上下文**：1M；**最大输出**：384K；思考模式默认开启
- **并发**：`deepseek-flash` 2500，`deepseek-v4-pro` 500（可免费扩容申请）
- **文档**：[Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing)、[Rate Limit](https://api-docs.deepseek.com/quick_start/rate_limit)
- 注：定价页提到扣费会「优先使用 granted balance（赠送余额）」，但**没有公开的赠送活动**，新账号通常是 0 余额。

### 1.4 阿里云百炼 DashScope（通义千问）✅ 推荐（额度大但一次性）

- **免费形式**：开通即送一次性 token 额度（据第三方：**超 7000 万 tokens，每个模型 100 万，有效期 90 天，仅华北2北京地域**）⚠️ **官方页面为 JS 渲染，未能逐字核实**
- **OpenAI 兼容 base_url**（官方文档原文）：
  ```
  北京：    https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
  旧北京：  https://dashscope.aliyuncs.com/compatible-mode/v1        （仍可用，不推荐）
  弗吉尼亚：https://dashscope-us.aliyuncs.com/compatible-mode/v1
  新加坡：  https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1
  东京：    https://{WorkspaceId}.ap-northeast-1.maas.aliyuncs.com/compatible-mode/v1
  ```
  - `{WorkspaceId}` 在百炼控制台「业务空间详情」页查看
  - 完整 endpoint：`POST {base_url}/chat/completions`
- **示例 model**：`qwen3.8-max`（官方示例）；模型列表见 [支持模型列表](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)
- **支持**：`stream: true`、`stream_options: {include_usage: true}`、tools / function call、`seed`、`stop`、`n`
- **⚠️ 关键坑**：**API Key 按地域绑定**。用北京 Key 调弗吉尼亚 endpoint → HTTP 401 `Incorrect API key provided` / `invalid_api_key`。必须在目标地域的控制台单独建 Key
- **账号要求**：阿里云账号 + 实名认证（个人或企业）
- **数据用于训练**：阿里云百炼企业版默认不用于训练，个人版需自行确认协议
- **文档**：[OpenAI Chat 接口兼容](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)

### 1.6 Moonshot Kimi ❌ 无免费额度

## 4. 推荐组合

| 场景 | 推荐 | 理由 |
|---|---|---|
| **日常轻量对话** | **智谱 `glm-4.7-flash`** | 永久免费、200K 上下文、128K 输出、中文好、大陆直连、支持流式与工具调用。综合最优 |
| **日常备用（智谱限流时）** | **硅基流动 `Qwen/Qwen3-8B`** | 永久免费、1000 RPM 比智谱宽松得多，适合被并发卡住时切过去 |
| **需要思维链 / 深度思考** | **`glm-4.7-flash`**（开 `thinking.type=enabled`）或硅基流动 `deepseek-ai/DeepSeek-R1-Distill-Qwen-7B` | 两者都免费且返回 `reasoning_content`，本项目 `reasoning: true` 可直接渲染思考面板。质量要求更高时付费上 `deepseek-flash`（1M 上下文，低峰便宜） |
| **完全离线** | **Ollama**（`http://127.0.0.1:11434/v1`） | 全免费、无实名、数据不出本机、无限流。建议 `qwen2.5:7b`（中文）或 `deepseek-r1:7b`（推理） |
| **大额度一次性白嫖** | **阿里云百炼**（约 7000 万 tokens / 90 天） | 额度最豪，适合短期压测或批量任务 |
| **海外高速备用** | Groq（快）/ Cerebras（RPD 最宽松） | 免费无卡，但大陆需自备网络 |

**建议的落地顺序**：先配 `glm-4.7-flash` 做主力 → 加 SiliconFlow 做备用 → 本地 Ollama 做离线兜底。

## 5. 风险提醒（务必阅读）

1. **免费渠道随时会变**。本次调研就撞到 GitHub Models 整体退役、智谱 GLM-4.5-Flash 下线、百炼换域名、混元老接口预下线。免费模型清单和 base_url **不要写死在代码里**，用 `.env` + `MODELS_JSON` 便于热切换。
2. **稳定性差**。免费档并发/RPM 都很低，高峰期容易 429 / 503。智谱错误码 1302（限流）、1305（平台过载）要单独处理并做指数退避。
3. **数据被用于训练**：
   - **Google Gemini 免费层**：官方明确在 UK/瑞士/EEA/EU 以外，prompt 会被用于训练、可能被人工审阅 —— 大陆用户属于「以外」，**即会被用于训练**。
   - **Mistral 免费层**：必须主动同意数据用于训练才能用。
   - **OpenRouter `:free` 模型**：底层 provider 策略不一，部分会记录。
   - 国内厂商（智谱/硅基流动/百炼/火山/混元/千帆）通常默认不用于训练，但**请自行阅读各自隐私政策**，不要把用户隐私数据送进去。
4. **实名要求**：所有国内渠道（智谱、硅基流动、百炼、火山、混元、千帆、ModelScope）都要实名认证，重度使用还可能要绑支付方式。个人开发者建议用个人实名。
5. **随时下线 / 模型改名**。`-Flash` 系列是厂商的试验田，下线公告往往只提前一两个月。**一定要做多厂商 fallback**。
6. **别被「免费」标题党骗**：智谱 `GLM-5.3-Flash`、`GLM-4.7-FlashX` 都是收费的；DeepSeek、Kimi 完全没有免费额度。真正免费的是我在 §1 里逐个列出的那些 model id。
7. **地域绑定坑**：百炼 API Key 按地域绑定，北京 Key 调新加坡 endpoint 直接 401，报错文案是 `Incorrect API key provided`，很容易误判为「Key 失效」。
8. **国内合规**：面向公众提供生成式 AI 服务需要备案，自己玩不受影响；商用请确认模型备案与内容安全要求（智谱有内容安全 API）。
